A deliberately vulnerable web app paired with a mitigated version for each vulnerability. Demo logins: alice / password123 or bob / hunter2.

Bryson Noble — Sensitive data in localStorage & cookies (XSS)

The vulnerable page stores a logged-in user's sensitive profile in localStorage and a JavaScript-readable cookie, letting a stored-XSS payload steal it. The mitigated page keeps the data in SQLite behind an httpOnly session cookie.
